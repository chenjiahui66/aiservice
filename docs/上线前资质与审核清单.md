**密钥泄漏自查方法**（提交前 / 上线前各跑一次）：

```bash
# 1. 确认 .env 被忽略
git check-ignore deploy/.env

# 2. 扫历史提交里是否出现过密钥
git log -p --all | grep -nE "(password|secret|appsecret|token)\s*[:=]\s*['\"]?[A-Za-z0-9+/]{16,}"
```

> ⚠️ **特别注意**：任何**启动脚本**里都不允许写密钥兜底默认值。
> `application-prod.yml` 依赖 `${JWT_PROVIDER_SECRET:?}` 在缺配置时启动失败，
> 若脚本先塞一个写死的默认值，这道防线就被架空，
> 生产环境会悄悄用上**公开可查的签名密钥**。
